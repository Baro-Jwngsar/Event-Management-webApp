About

Events managed online, from first poster to last seat

Manch brings event planning, registration and updates into one website. People can check dates, see the venue, register for a seat and reach the host without chasing anyone on chat.

The same site grows with the work. New event types and categories can be added as the host takes on more.

How it works for a visitor

  1. 1
    Check upcoming events.
    Filter by student, teacher or public.
  2. 2
    Fill the registration form.
    Or scan the QR code on a poster.
  3. 3
    Find the venue.
    Address and map link on every event.
  4. 4
    Get in touch with the host.
    Call or message with any question.
